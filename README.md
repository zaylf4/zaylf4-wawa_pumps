# Wawa Fuel Stations ⛽

A simple **Wawa-inspired rebrand of GTA V fuel pumps** for FiveM.

Replace the default GTA V fuel pump branding with Wawa-style branding while keeping the original GTA V models and locations.

## ✨ Features

* Wawa-inspired fuel pump branding
* Replaces vanilla pump textures
* Keeps original GTA V pump models
* Works across compatible fuel pumps
* Lightweight FiveM resource
* No scripts or dependencies required

## 📦 Installation

1. Download the resource.
2. Place it in your FiveM `resources` folder.
3. Add the following to `server.cfg`:

```cfg
ensure zaylf4-wawa_pumps
```

4. Restart your server.
